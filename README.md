## 🌐 О сайте

Это мой персональный сайт-портфолио, созданный с нуля на React + Tailwind CSS.

### 🔍 Особенности:
- ✅ Адаптивный дизайн (мобильные устройства, планшеты, десктоп)
- ✅ Интерактивные проекты (включая калькулятор с QR-кодом и Easter Egg)
- ✅ Навигация с плавным скроллом
- ✅ Стилизованные карточки проектов
- ✅ Контакты с иконками GitHub, Email, Telegram

---

## 💡 Технологии

- **React** (Functional Components, Hooks: `useState`, `useEffect`)
- **Tailwind CSS** — для стилизации
- **Vercel** — для хостинга и деплоя
- **JavaScript ES6+**
- **HTML5 / CSS3**

---

## 📁 Структура проекта

src/

## 🚀 Как запустить локально

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/gfux/ftarasow-portfolio.git

# 2. Перейдите в папку
cd ftarasow-portfolio

# 3. Установите зависимости
npm install

# 4. Запустите сервер разработки
npm start

# Откроется http://localhost:3000
